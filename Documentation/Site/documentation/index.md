# Start with a test. Then make it a snapshot.

The guide covers installation, recording, and the everyday workflow. API documentation covers the modules in this package.

[Getting started](/docs/swift-snapshot-testing/documentation/getting-started/) — Add the package, write your first assertion, and understand recorded references.

[SnapshotTesting](/docs/swift-snapshot-testing/api/snapshottesting/documentation/snapshottesting/) — Assertions, strategies, recording options, and configuration.

[SnapshotPreviews](/docs/swift-snapshot-testing/api/snapshotpreviews/documentation/snapshotpreviews/) — Share SwiftUI preview definitions with snapshot tests.

[InlineSnapshotTesting](/docs/swift-snapshot-testing/api/inlinesnapshottesting/documentation/inlinesnapshottesting/) — Store a compact text snapshot beside its assertion.

[CustomDump](/docs/swift-snapshot-testing/api/customdump/documentation/customdump/) — Produce focused structural snapshots using the CustomDump module.
